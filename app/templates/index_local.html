iPhone camera stream

This laptop is running the server. Open the desktop viewer, then connect the iPhone with the QR code.

Open desktop viewer

  1. Leave this server running.
  2. Start the Cloudflare tunnel in another terminal.
  3. Generate the QR code and scan it with the iPhone Camera app.
  4. In Safari, tap Start Camera and allow the rear camera.

The commands are in README.md. Frames are kept in memory and are not recorded.
